# Reproducible experiment results (Git history)

`repro_latest.json` and `scan_latest.json` are generated by GitHub Actions. Each saved Git commit retains the then-current official-price snapshot, provenance, replay proof, code hash, dependency versions, and search protocol. Do not change these files by hand.

No brokerage account identifiers, private API keys or execution history. `approved_for_live_trading=false` is mandatory. Repeatedly using the fixed holdout to change candidate design invalidates its independence.
